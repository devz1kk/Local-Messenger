# 🌊 ВОЛНА — Настольный мессенджер

Современный, легковесный и визуально выразительный десктопный клиент мессенджера на стеке **Python 3.10+ + pywebview (Edge WebView2) + HTML5/CSS3/JS**, оформленный в футуристичной киберпанк/неоновой стилистике с аппаратным скруглением окон Win32.

---

## ⚡ Ключевые возможности

- **🔄 Интеллектуальная система самообновления (GitHub OTA)**:
  - **Сверка Git Blob SHA-1**: Клиент рассчитывает точный хеш локального исполняемого файла по алгоритму Git (`sha1("blob " + size + "\0" + data)`) и сравнивает его с удаленным хешем через GitHub Contents API.
  - **Фоновая докачка и валидация**: При обнаружении новой версии бинарник скачивается в `update_pending.exe` и проходит обязательную проверку контрольной суммы (защита от битых файлов / anti-bricking).
  - **Модальное окно обновления (`update.html`)**: Всплывающее неоновое окно поверх всех окон с выбором действия: «Установить сейчас» или «Позже».
  - **Тихий отложенный апдейт**: Если нажато «Позже», при следующем запуске программа мгновенно подменяет бинарник еще до старта сокетов и графического интерфейса.
  - **Безопасная подмена через Batch-скрипт**: Внешний скрипт отслеживает завершение процесса по PID, сбрасывает виртуальное окружение PyInstaller (`_MEIPASS2`, `_PYI_*`), перезаписывает `.exe`, запускает новую версию и самоудаляется.
  - **Dev Mode Protection**: При запуске из исходников (`python main.py`) замена исполняемого файла блокируется для защиты системного интерпретатора Python.

- **📝 Изолированное логирование сессии обновления (`volna_update.log`)**:
  - Логирование запускается при старте подсистемы обновления (1 запуск = 1 файл, перезаписывается при старте).
  - Фиксируются все тайминги, сетевые статусы, SHA-хеши, процесс загрузки и шаги работы батника.
  - Пользовательские сообщения чата не логируются в целях конфиденциальности и производительности.

- **🪟 Аппаратное скругление Win32 (Pixel-Perfect Masking)**:
  - Интеграция с Win32 GDI32 API (`CreateRoundRectRgn` + `SetWindowRgn`).
  - Устранение черных углов, системных рамок и белых вспышек при инициализации DirectX/WebView2 слоев как в основном окне, так и во всплывающих виджетах.

- **🔔 Неоновые веб-уведомления (`toast.html`)**:
  - Компактный frameless-виджет над системной панелью задач (в правом нижнем углу).
  - Превью текста, отправителя, времени и миниатюр картинок с автозакрытием по таймеру или клику.

- **Медиа, файлы и Drag & Drop**:
  - Прямое перетаскивание файлов любого типа в окно мессенджера.
  - Встроенный рендеринг изображений, аудио и видеоплееров (`.mp4`, `.webm`, `.mp3`, `.ogg` и др.).
  - Автоматическое фоновое скачивание документов в локальную папку `downloads/`.

- **Полнофункциональный Frameless-дизайн**:
  - Перемещение окна за шапку со скоростью 60 FPS через `requestAnimationFrame`.
  - Изменение размеров (Resize) во все 8 направлений (`N, S, E, W, NW, NE, SW, SE`).
  - Сворачивание в системный трей (Pystray) и интеграция с панелью задач Windows.

- **Интерактивные возможности**:
  - Эмодзи-реакции на сообщения (`❤️, 🔥, 😂, ✨, 👍, 🚀`) с синхронизацией между участниками.
  - Автоматический сбор превью для внешних ссылок (OpenGraph Link Previews).
  - Анимированный интерактивный Canvas-фон, реагирующий на курсор мыши.

## 🛠️ Установка и запуск

### 1. Системные требования
- **Python 3.10+**
- Операционная система: **Windows 10 / 11** (полная поддержка аппаратных масок GDI32 и WebView2)
- Установленный рантайм **Microsoft Edge WebView2** (по умолчанию присутствует в Windows 10/11)

### 2. Установка зависимостей
```bash
pip install pywebview pystray Pillow
```

### 3. Запуск из исходников
```bash
python main.py
```
*При первом старте приложение сгенерирует недостающие иконки, создаст необходимые папки и разместит значок в системном трее.*

## 🔌 Сетевой протокол (TCP + UDP)

1. **UDP Auto-Discovery (порт 12346)**:
   - Клиент слушает широковещательные пакеты локальной сети для автоматического обнаружения IP-адреса сервера без ручного ввода.
2. **TCP-транспорт (порт 12345)**:
   - Бинарный фрейминг: `[4 байта Big-Endian: длина пакета] + [JSON Payload UTF-8]`.
   - Автоматическое восстановление соединения с запросом пропущенной истории чата при обрыве сети.

## 📦 Сборка в автономный .exe (PyInstaller)

Для сборки стабильного монолитного `.exe` со всеми встроенными HTML-интерфейсами и ресурсами выполните команду:

```bash
pyinstaller --noconfirm --onefile --noconsole --add-data "web;web" --icon "web/icon.ico" --hidden-import "clr" --hidden-import "clr_loader" --hidden-import "pythonnet" --hidden-import "pystray._win32" --hidden-import "tkinter" --collect-all "webview" --collect-all "setuptools" main.py
```

Готовый файл будет расположен в папке `dist/main.exe`.
