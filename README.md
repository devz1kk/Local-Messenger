# Local-Messenger
---
# 🌊 ВОЛНА — Настольный мессенджер

Современный, легковесный и визуально выразительный десктопный клиент мессенджера на стеке **Python + pywebview + HTML5/CSS3/JS**, упакованный в футуристичный неоновый интерфейс.

---

## ⚡ Ключевые возможности

- **Мгновенное открытие за 0 мс (Pre-warm рендеринг)**: Окно подготавливается и прогревается в фоне за пределами экрана, открываясь из трея моментально без белых вспышек и задержек инициализации.
- **Интерактивный ползунок навигации**: Кастомный неоновый скроллбар с динамическим расчётом высоты, плавным перетаскиванием (drag-and-drop), быстрым прыжком по клику и кнопкой возврата вниз.
- **Полнофункциональный Frameless-дизайн**: Кастомная шапка окна, перемещение с плавностью 60 FPS и растягивание границ во все 8 направлений (`N, S, E, W, NW, NE, SW, SE`).
- **Сворачивание в системный трей (Pystray)**: Работа в фоне, значок в трее с контекстным меню и автоприменение иконок в панели задач Windows.
- **Неоновые Toasts-уведомления**: Всплывающие карточки входящих сообщений и файлов на базе Tkinter поверх всех окон.
- **Медиа и файлы (Drag & Drop)**:
  - Прямое перетаскивание файлов в окно мессенджера.
  - Встроенный плеер для аудио и видео (`.mp4`, `.mp3`, `.ogg`, `.webm` и др.).
  - Галерея изображений с открытием в один клик.
  - Автоматическая докачка файлов в папку `web/downloads/`.
- **Эмодзи-реакции**: Всплывающая панель реакций на сообщения (`❤️, 🔥, 😂, ✨, 👍, 🚀`) с синхронизацией счётчиков в реальном времени.
- **Rich OpenGraph Link Previews**: Автоматический парсинг метаданных ссылок (заголовок, домен, описание) в фоновом потоке.
- **Поддержка кастомных курсоров**: Автоматическая подгрузка `.png` / `.cur` курсоров из папки `web/cursors/`.

🛠️ Установка и запуск
1. Требования
Python 3.10+
Операционная система: Windows 10/11, Linux или macOS.
2. Установка зависимостей
code
Bash
pip install pywebview pystray Pillow
Примечание для Linux: может потребоваться установка python3-tk и бэкенда WebKit (gir1.2-webkit2-4.0 или PyQt5 / PyQtWebEngine).
3. Запуск
code
Bash
python main.py
Приложение создаст необходимые директории, инициализирует иконки и запустится в системном трее.
🔌 Сетевой протокол (TCP + UDP)
Клиент использует надежный бинарный фрейминг:
UDP Auto-Discovery: Поиск активного сервера в локальной сети на порту 12346.
TCP-пакеты: [4 байта Big-Endian: длина JSON] + [JSON Payload UTF-8].
Автореконнект: Автоматическое переподключение и восстановление истории при разрыве связи.
📦 Сборка в автономный .exe (PyInstaller)
Для сборки единого исполняемого файла для Windows:
code
Bash
pip install pyinstaller
pyinstaller --noconfirm --onedir --windowed --add-data "web;web" --icon "web/icon.ico" main.py
Собранная программа будет находиться в каталоге dist/main/.
